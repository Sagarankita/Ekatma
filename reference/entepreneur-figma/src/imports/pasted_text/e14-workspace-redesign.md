CORRECT THE EXISTING E14 APPLICATION WORKSPACE — DO NOT REBUILD THE FUNCTIONAL FLOW.

The current E14 screen has become visually inconsistent with the established EKATMA Entrepreneur interface. Keep the existing E14 functionality, fields, sections, states, and prototype links, but **redesign its visual presentation so it belongs to the same product as the existing EKATMA pages**.

The target is the established EKATMA government-portal interface, especially the visual language already used by the existing Document Centre and other completed Entrepreneur screens.

## 1. REMOVE THE AI-GENERATED / GENERIC DASHBOARD LOOK

The current page feels like a generic AI-generated SaaS application rather than EKATMA.

Correct this by removing:

* Emoji-style icons such as 📋, 🏢, 📄, 📁, 🔍, etc.
* Decorative icons used only to make sections look visually interesting
* Large rounded dashboard cards
* Excessive card-within-card layouts
* Overly colorful status treatments
* Large blue application-specific header areas
* The dark navy application header that visually separates E14 from the rest of EKATMA
* Unnecessary visual decoration
* Excessive rounded corners
* Heavy borders around every small element
* Generic SaaS-style stepper/card UI

Do not replace these with another decorative style.

The interface should become **simpler, flatter, more institutional, and more like a real Government of Maharashtra portal**.
